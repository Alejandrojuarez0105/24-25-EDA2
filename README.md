# Ordenación

Esta rama ha sido creada con el objetivo de implementar y comparar distintos métodos de ordenación aplicados a los datos contenidos en el archivo **Cliente.java**.

## ¿Qué se busca?

El propósito de esta sección es desarrollar e integrar la mayor cantidad posible de algoritmos de ordenación clásicos y modernos. No solo se pretende que los datos sean correctamente ordenados, sino también analizar y comparar:

- **La eficiencia en tiempo de ejecución**, midiendo cuánto tarda cada algoritmo en ordenar distintos volúmenes de datos.
- **El consumo de recursos**, especialmente la memoria utilizada por cada técnica.
- **La complejidad algorítmica**, tanto en el peor como en el mejor de los casos.
- **La facilidad de implementación y mantenibilidad** dentro del contexto del proyecto.
- **La aplicabilidad práctica**, evaluando cuál método es más apropiado según el tipo de datos, el tamaño del conjunto y los requerimientos del sistema.
